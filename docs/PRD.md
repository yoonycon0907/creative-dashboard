# PRD — 메타 광고 소재(이미지)별 성과 대시보드

문서 버전 v1.0 · 작성일 2026-09-04 · 작성 목적: Claude Code로 자체 제작

---

## 1. 개요

메타 광고관리자는 "광고(ad) 행 단위"로만 보여주기 때문에, **같은 소재가 여러 광고세트·커머스에 흩어져 있으면 그 소재가 실제로 잘하는지 판단할 수 없다.** 이 대시보드는 광고 행이 아니라 **소재(이미지/영상 에셋) 단위로 성과를 합쳐서, 썸네일과 함께 눈으로 보는** 읽기 전용(read-only) 뷰어다.

- **핵심 문장**: "이 이미지, 전체 계정 통틀어 지금까지 얼마 쓰고 ROAS 몇 %야?"에 3초 안에 답하는 화면
- **범위 제외**: 광고 생성·UTM 세팅·자동 업로드 등 쓰기(write) 기능 일체 없음

## 2. 문제 정의

| 현재 | 문제 |
|---|---|
| 광고관리자에서 ad_name으로 성과 확인 | 동일 소재가 싱글/컬렉션/카탈로그 형식, 3개 계정(CJDPM·컬리·네이버)에 중복 존재 → 소재 단위 합산 불가 |
| 엑셀·Windsor 조회로 리포트 | 숫자만 보여 **어떤 그림이었는지** 기억에 의존 |
| 소재 모듈(X·Y·컨셉·형식) 분류 | 성과 데이터와 분리되어 있어 "어떤 축이 이기는가" 검증이 수작업 |

## 3. 목표 / 성공 지표

| 목표 | 성공 기준 |
|---|---|
| 소재 단위 성과 판독 시간 단축 | 소재 1건 판단까지 3초 (썸네일 + 지출 + ROAS + CPP) |
| 소재 자산 누적 | 종료된 소재 포함 전 기간 이력 보존 |
| 신뢰 | 대시보드 합계 = 광고관리자 합계 (오차 ±1% 이내, 기여기간 명시) |

## 4. 데이터 소스 및 정합성 규칙

### 4.1 소스
**Meta Marketing API v26.0 직접 호출** (2026-07-29 릴리스 기준)

### 4.2 계정 및 기여기간 (계정별로 다름)

| 계정 | ID | 전환 필드 | attribution |
|---|---|---|---|
| CJDPM(자사몰) | 755429019968813 | `actions:omni_purchase`, `action_values:omni_purchase` | `1d_click` |
| 컬리(협력광고) | 662564306201450 | `catalog_segment_actions`, `catalog_segment_value` | `1d_view,1d_click` |
| 네이버(협력광고) | 517752597868803 | `catalog_segment_actions`, `catalog_segment_value` | `1d_view,1d_click` |

### 4.3 소재 식별 키

```
creative_key =
  video_id           (영상 소재)
  or image_hash      (단일 이미지)
  or asset_feed 첫 번째 에셋 해시  (다이나믹 소재)
  or "CATALOG:" + product_set_id   (카탈로그 소재)
```

- 같은 creative_key를 가진 광고 N개의 지표는 **단순 합산**(지출·노출·클릭·구매·구매액), 비율 지표(CTR·CPC·ROAS)는 **합산값으로 재계산**
- **형식 태그**: 캠페인·광고명의 `single`/`collection`/`catalog` 키워드로 자동 판별
- **카테고리 태그**: 캠페인명 키워드 매핑

### 4.4 동기화
- 일 1회 배치(새벽 06:00) + 수동 [새로고침] 버튼
- `level=ad`, `time_increment=1` (일자별 저장)
- 최초 적재: 과거 12개월 → 계정별로 월 단위 끊어서 순차 호출
- 증분: 최근 7일 재조회 후 upsert (전환 지연 반영)

## 5. 지표 정의서

| 지표 | 정의 |
|---|---|
| ROAS | 구매전환값 ÷ 지출 × 100 (**% 표기**. API는 배수 반환 → 변환 필수) |
| CPP | 지출 ÷ 구매수 |
| CVR | 구매수 ÷ 링크클릭 |
| CTR | 클릭 ÷ 노출 |
| CPC | 지출 ÷ 클릭 |
| CPM | (지출 ÷ 노출) × 1000 |

## 6. 비기능 요구사항

- **접근**: 개인/팀 내부용. Vercel 배포 시 최소한 Basic Auth 또는 Vercel Password Protection 적용
- **토큰**: 시스템 유저 장기 토큰, `ads_read` 권한만. `.env`에만 저장, 커밋 금지
- **성능**: 소재 1,000건 그리드 초기 로딩 2초 이내
- **데이터 미조회 시**: 숫자를 채워 넣지 않고 "조회 실패"를 화면에 명시

## 7. 마일스톤

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| M1 | API 연결 + 일자별 ad 레벨 적재 → SQLite | 광고관리자 합계와 지출·구매 대사 성공 |
| M2 | 소재 그룹핑(creative_key) + 썸네일 캐싱 + 카드 그리드 | 썸네일 보이고 소재 단위 합산 정상 |
| M3 | 상세 패널(누적/기간/일별 추이/영상 퍼널/세트별 분해) | 영상 소재 리텐션 곡선 표시 |
| M4 | 메모·모듈 태그·위너, 축별 분석, 자동 진단, 배포 | 실사용 전환 |
